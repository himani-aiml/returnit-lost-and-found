The Problem

Things get lost.
They rarely get found.

Every day in schools, hospitals, and public spaces — people lose wallets, phones, keys, ID cards — with no system to report or search for them. The person who found your item has no way to reach you. You have no way to know it's even been found.

  • ❌
    No reporting system No digital way to formally report a lost or found item anywhere.
  • 🔍
    No way to search Even if someone found your item, you'd never know to look for it.
  • 📭
    No notifications No one tells the owner when a matching item shows up — ever.

How It Works

Four steps.
One resolution.

ReturnIt keeps it simple. No accounts needed, no complicated forms — just report, search, match, and connect.

1

Report your item

Fill in the item name, description, category, where it was lost or found, and the date. Takes under a minute.

Lost  Found
2

Browse and search

Anyone can browse all reported items, search by keyword, and filter by category or type in real time.

Instant results
3

Let AI find matches

Hit "Find AI Matches" on any item and Google Gemini compares it against everything reported — returning the top 3 matches with a match percentage and a clear reason why they match.

✨ Powered by Gemini API
4

Connect and resolve

Contact details are shown directly so the owner and finder can connect and close the case.

Case closed
🤖

AI Matching — the core differentiator

Most lost & found systems just let you post and hope. ReturnIt uses Google Gemini API to intelligently compare a lost item against all found items — considering synonyms, category, location, and date — and returns ranked matches with a human-readable explanation. A black wallet can match a "dark leather card holder." That's the difference.

Quick Start

Run it locally.

# clone the repo
git clone https://github.com/your-username/returnit-lost-and-found
cd returnit-lost-and-found

# install dependencies
npm install

# add your Gemini API key in .env
VITE_GEMINI_API_KEY=your_key_here

# start dev server
npm run dev
